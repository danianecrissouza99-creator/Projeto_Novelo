# Novelo

Bichinho virtual com um gatinho de peluche: dá-lhe comida, banho e mimos, põe-no a dormir, joga mini-jogos para ganhar moedas e compra-lhe roupas.

**Jogar:** https://danianecrissouza99-creator.github.io/Projeto_Novelo/

## Sobre o projeto

Projeto da UC **Testes e Qualidade de Software** — ISTEC.
O jogo foi feito para ser testado por um colega, que deve procurar os defeitos comparando o comportamento do jogo com as regras.

- Funciona no browser, no computador ou no telemóvel (rato, teclado ou toque).
- O progresso fica gravado no próprio browser.

## Tecnologias

HTML, CSS e JavaScript, sem bibliotecas. O gatinho e os mini-jogos são desenhados com a Canvas API.
